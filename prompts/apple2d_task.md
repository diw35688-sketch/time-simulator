# 任务：用一张苹果图做「过去 ↔ 现在 ↔ 未来」的 three.js 时间原型

你只负责「物品随时间变化」这一层。手势和法阵由另一个页面负责，它会通过下面的接口驱动你。

## 输入
- `assets/apple.png`：一张透明底 PNG，里面是一个红苹果（带梗和一片叶子），已经裁到苹果边缘，宽高比不固定，运行时读 `naturalWidth/naturalHeight`。这是唯一的素材，不允许再引入其它图片、模型或纹理文件。

## 产出
- 单文件 `apple_time.html`，放在项目根目录（与 `assets/` 同级）
- three.js 用 importmap 从 `https://cdn.jsdelivr.net/npm/three@0.160.0/` 引入，版本写死；不要用其它库

## 时间定义（核心）
`t ∈ [-1, 1]`，连续可来回拨：
- `t = 0`：现在。画面必须和 `apple.png` 原图几乎一致
- `t → -1`：过去。倒推这个苹果的来历，例如：青涩小果 → 花谢 → 苹果花（具体节奏你来设计）
- `t → +1`：未来。例如：被咬一口 → 褐变、起皱 → 霉斑 → 干瘪塌陷（具体节奏你来设计）

**硬性要求：画面必须是 t 的纯函数。** 不许依赖累积状态或随机数，同一个 t 每次渲染出的画面必须一样，这样往回拨才能精确复原。可以有与 t 无关的微小待机动效（比如轻微呼吸），但关掉后画面也必须只由 t 决定。粒子、花瓣之类用固定种子，位置由 t 计算得出。

技术手段随你选：着色器（颜色、褶皱、置换、溶解）、几何变形、程序生成的花瓣或叶片、贴花等等。目标是看起来连贯、有质感，而不是在几张图之间交叉淡化。

## 接口（必须实现）
```js
window.setTime(t)                // 外部设置时间，自动截断到 [-1, 1]
window.getTime()                 // 返回当前 t
window.addEventListener('message', e => { if (e.data?.type === 'timespell:setTime') setTime(e.data.t) })
window.__timeState = () => ({ t, fps })   // 用于自动化测试
```

## 两种模式
- 默认（独立模式）：深色背景，底部有一个滑块（-1 到 1，步长 0.001），在滑块上方显示当前阶段的名字；键盘 ← → 键微调
- `?embed=1`（嵌入模式）：背景透明（`alpha: true`，clearAlpha 0），不显示任何 UI。苹果的中心放在画面 (50%, 60%) 处，苹果的显示尺寸约为 `min(宽, 高) × 0.35`。窗口缩放时自适应

## 验收标准（会逐条检查）
1. 打开后控制台没有任何报错
2. 在集成显卡上帧率 ≥ 30
3. `setTime(0)` 时的画面和原图一致
4. 依次 `setTime(0.7)`、`setTime(-0.5)`、`setTime(0.7)`，第一次和第三次的画面逐像素相同（检验是否为纯函数）
5. 嵌入模式下背景透明、没有 UI
6. 不用 `apple.png` 以外的素材，不出现任何文字水印或品牌元素

只交付 `apple_time.html` 一个文件，并用一句话说明你为过去和未来各设计了哪几个阶段。
